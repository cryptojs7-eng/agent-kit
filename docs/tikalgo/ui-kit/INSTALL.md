# TIKALGO UI kit: نصب و محل استفاده در پروژه

این پوشه ۱۷ کامپوننت آماده دارد که از پرامپت‌های `prompts/ui/` ساخته شده‌اند.

**ویژگی‌های مشترک همهٔ صفحه‌ها:**
- با **Tailwind CSS** و **JavaScript ساده** نوشته شده‌اند و رنگ‌ها و لوگوی برند TIKALGO را دارند.
- کاملاً قابل‌استفاده‌اند: کیبورد، ARIA، حالت فوکوس، و پشتیبانی **RTL**. هر صفحه یک دکمهٔ RTL/LTR دارد.
- هرکدام یک **نمونهٔ مستقل (prototype)** است. باید به فریم‌ورک فرانت‌اند پروژه (`/root/tikalgo`) منتقل شود و به **API واقعی** وصل شود.
- عددهای نمایشی فقط برای نمونه هستند. در محصول هیچ دادهٔ ساختگی نباید بماند.

## پیش‌نمایش
- **روی کامپیوتر:** پوشهٔ `docs/tikalgo/ui-kit/` را باز کنید و `index.html` را در مرورگر اجرا کنید. گالری همهٔ صفحه‌ها را نشان می‌دهد.
- **روی سرور:**
  ```bash
  cd /root/tikalgo/docs/tikalgo/ui-kit && python3 -m http.server 8090
  ```
  سپس `http://SERVER_IP:8090` را باز کنید. **فقط موقت**؛ پورت را بعداً ببندید.

## فایل‌های مشترک
| فایل | نقش | در پروژه |
|---|---|---|
| `assets/tikalgo.js` | تنظیمات Tailwind (رنگ‌های `ink`، `brand`، `ai`، `down` و فونت‌ها) و نوار نمایشی RTL | رنگ‌ها و فونت‌ها را در `tailwind.config` پروژه بگذارید. نوار نمایشی را **منتقل نکنید**؛ فقط برای پیش‌نمایش است |
| `assets/tikalgo-logo.svg`، `tikalgo-mark.svg`، `favicon.svg` | لوگو | همان فایل‌های `docs/tikalgo/brand/` (بخش «Install into the TIKALGO frontend» در README برند) |

| توکن | مقدار | کاربرد |
|---|---|---|
| `ink` | `#0A1712` | دکمه‌ها و پس‌زمینهٔ تیره |
| `brand` | `#3DDC2F` | سبز برند، سود، فوکوس |
| `brand-dark` | `#1FA81F` | سبز روی پس‌زمینهٔ روشن |
| `ai` | `#FF7A1A` | **فقط** المان‌های هوش مصنوعی |
| `down` | `#F6465D` | ضرر و منفی |

## روش انتقال به پروژه
به Claude Code روی سرور (`cd /root/tikalgo && claude`) بگویید:

```text
کامپوننت @docs/tikalgo/ui-kit/<FILE>.html را طبق قواعد @docs/tikalgo/prompts/ui/README.md
و جدول محل استفاده در @docs/tikalgo/ui-kit/INSTALL.md به فرانت‌اند فعلی TIKALGO منتقل کن:
- به همان فریم‌ورک و ساختار کامپوننت‌های موجود تبدیل کن (کامپوننت تکراری نساز)،
- رنگ‌ها و فونت‌ها را از tailwind.config پروژه بخوان (توکن‌های ink/brand/ai/down)،
- متن‌ها را در سیستم ترجمهٔ فعلی (فارسی/انگلیسی) بگذار و RTL را تست کن،
- همهٔ اعداد نمایشی را به API واقعی وصل کن؛ هیچ mock یا fake success باقی نماند،
- اعتبارسنجی امنیتی (کد، 2FA، نقش‌ها) را سمت سرور انجام بده،
- تست و build را اجرا کن و گزارش فارسی بده.
```

**مثال‌ها:**
- `کامپوننت @docs/tikalgo/ui-kit/01-otp.html را ... به صفحهٔ ورود منتقل کن.`
- `کامپوننت @docs/tikalgo/ui-kit/14-mobile-nav.html را ... به layout موبایل منتقل کن.`

**ترتیب پیشنهادی:**
1. `14-mobile-nav` (پوستهٔ موبایل)
2. `01-otp`، `02-two-factor`، `03-email-verify` (امنیت)
3. `07`، `08`، `09` (داشبورد و سلامت TIKALGO AI)
4. `05`، `04`، `06`، `11` (لندینگ)
5. `15`، `16`، `17` (ادمین)
6. `10`، `12`، `13` (اختیاری)

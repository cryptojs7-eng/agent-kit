# صفحهٔ عمومی TIKALGO (www.tikalgoai.com): نصب و راه‌اندازی

این پوشه صفحهٔ اصلی عمومی سایت است. چیدمان و فضای آن از طرح Lovable شما (`pixel-perfect-flow-92.lovable.app`) الهام گرفته، ولی **از نو** ساخته شده و این‌ها را دارد:
- **لوگوی واقعی تیکالگو** و رنگ‌های برند؛
- **توضیحات واقعی پروژه**: بازارها، TIKALGO AI آفلاین، مسیر تصمیم، مدیریت ریسک، تیکا و پلن‌ها؛
- **موشن** با GSAP و ScrollTrigger؛
- **دو زبان** انگلیسی و فارسی، همراه با RTL؛
- **چت‌بات فعال تیکا** با آواتار تیکا؛
- **بدون ثبت‌نام عمومی و بدون پلن رایگان**: همهٔ دکمه‌ها به `/login` می‌روند.

## چت‌بات تیکا
- دکمهٔ شناور با آواتار تیکا در گوشهٔ صفحه است. بعد از ۴ ثانیه یک پیام خوش‌آمد کوتاه هم نشان می‌دهد.
- **دو حالت پاسخ:**
  1. **با بک‌اند تیکا:** اول درخواست `POST /api/tika/chat` با بدنهٔ `{ message, lang, history }` ارسال می‌شود و انتظار پاسخ `{ reply }` را دارد. این همان دستیار فقط‌خواندنی، آموزشی و محرمانه با مدل محلی است (بخش ۱۴ پرامپت اصلی). برای فعال شدنش باید این endpoint در بک‌اند TIKALGO ساخته یا وصل شود.
  2. **بدون بک‌اند:** اگر endpoint در دسترس نباشد، از **پایگاه دانش داخلی دوزبانه** جواب می‌دهد. یعنی روی هاست استاتیک هم کار می‌کند.
- **ایمنی:**
  - درخواست توصیهٔ خرید یا فروش (مثل «الان BTC بخرم؟») رد می‌شود و تیکا فقط توضیح آموزشی می‌دهد.
  - سؤال دربارهٔ معماری، سرور، کلید یا پرامپت هم پاسخ «محرمانه» می‌گیرد.
- **افزودن پرسش و پاسخ:** آرایهٔ `KB` در `assets/tika-chat.js` را ویرایش کنید.

## دیپلوی روی www.tikalgoai.com (Nginx)
```bash
# روی سرور
sudo mkdir -p /var/www/tikalgo-landing
sudo cp -r /root/tikalgo/docs/tikalgo/landing/{index.html,assets} /var/www/tikalgo-landing/
```
```nginx
server {
    server_name tikalgoai.com www.tikalgoai.com;
    root /var/www/tikalgo-landing;

    location = / { try_files /index.html =404; }
    location /assets/ { expires 7d; add_header Cache-Control "public"; }

    # Terminal app (login, dashboard) and API stay on the existing app server:
    location /login { proxy_pass http://127.0.0.1:<APP_PORT>; }
    location /api/  { proxy_pass http://127.0.0.1:<API_PORT>; }
    # ...other existing app routes stay unchanged
}
```
- `<APP_PORT>` و `<API_PORT>` را با پورت‌های واقعی برنامه جایگزین کنید.
- اگر فرانت‌اند TIKALGO صفحهٔ اصلی خودش را دارد، می‌توانید به‌جای Nginx همین صفحه را به route اصلی آن فریم‌ورک منتقل کنید.
- بعد از تغییر: `sudo nginx -t && sudo systemctl reload nginx`.

## نکات
- **فونت‌ها** از Google Fonts و **GSAP** از cdnjs بارگذاری می‌شوند. اگر GSAP بارگذاری نشود، صفحه با انیمیشن سادهٔ داخلی همچنان کامل نمایش داده می‌شود.
- تنظیم «کاهش حرکت» سیستم کاربر رعایت می‌شود.
- نمودارهای صفحه **نمایشی** هستند و این روی صفحه نوشته شده است. اعداد بخش آمار (۷ مرحله، ۱۲ لایه، ۵ بازار، ۰ فراخوانی AI ابری) توصیف طراحی هستند، نه نتیجهٔ معاملاتی.
- **هیچ ادعای سوددهی** در صفحه نیست و هشدار ریسک در فوتر و بخش فرایند آمده است.
- **وضعیت اتصال صرافی‌ها** («در حال ارزیابی») را با پیشرفت واقعی به‌روز کنید.
